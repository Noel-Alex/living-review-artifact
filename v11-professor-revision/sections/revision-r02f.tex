\section{Analyses Added for the Second Review}\label{sec:r02}
Each analysis below followed a protocol whose text and code hashes were recorded before its new outcomes were computed; the re-aggregation, strata, identity-floor and policy analyses read records whose outcomes had already been seen (tier E1) (\texttt{review/V12-PROTOCOL-K*.md}, \texttt{evidence/v12-wpk*}); amendments were recorded before the outcomes they concern. The 16-page paper summarizes them; the tables are in Appendix~\ref{app:r02}.

\subsection{Six Outcomes, Strata, Identity Floor and Policy Selection}
Tables~\ref{tab:wpk1-sixoutcome-part1}--\ref{tab:wpk1-sixoutcome-part6} re-aggregate every saved population and configuration into the six outcomes (placement, missed re-check, silent misplacement, misdirected request, lost anchor, unnecessary re-check), each with its numerator and denominator, and Table~\ref{tab:wpk1-chains-h10} does the same for the ten-commit chains. Tables~\ref{tab:wpk1-strata-part1}--\ref{tab:wpk1-strata-part15} stratify the outcomes by anchor length, anchors per issue and the locator's confidence crossed with the guards. Tables~\ref{tab:wpk1-idfloor-part1}--\ref{tab:wpk1-idfloor-part6} replay every identity-rule floor from 0.3 to 1.0 on the stored chain traces: missed changes since review do not depend on the floor, which only trades wrong endpoints for lost ones. Tables~\ref{tab:wpk1-policy} and~\ref{tab:wpk1-lopo} select a whole deployment policy on eight projects and evaluate it on the ninth (post hoc): selection beat the deployed cascade on every held-out project but did not reliably beat a fixed CodeMapper+IG+AGi, and the folds chose different policies.

\subsection{Blinded Adjudication of the Syntax-Tree Reference}\label{sec:r02refaudit}
Two hosted models, not people, re-decided \wrAllN{} stratified targets and \wrExclN{} excluded candidates blind to the reference and to every method, from the old excerpt with the reviewed lines marked and the paired new file (Table~\ref{tab:refaudit}). They agreed with the reference on \wrPairBeamStatus\% and \wrPairNemoStatus\% of the targets decided by same-type pairing and on \wrAlignedBeamStatus\% of the aligned controls. Agreement was lowest where the reference relocates code to another file, which the input does not show (on targets where the methods disagree, \wrDisBeamStatus\% and \wrDisNemoStatus\% overall but \wrDisWithinBeamStatus\% and \wrDisWithinNemoStatus\% of the \wrDisWithinN{} kept in the file), and where it reports a deletion: of the \wrDelWithinN{} deletions and relocations inside the paired file, both models contradicted the reference on \wrDelWithinSuspect{}, and on \wrDelWithinEdited{} of them found the code edited rather than deleted, a change either way. On the deployed cascade's \wrMissN{} misses the models agreed with the reference on \wrMissBeamStatus\% and \wrMissNemoStatus\%, and both contradicted it on \wrMissSuspect{}: on \wrMissLowering{} both called the code unchanged, which would lower the miss count, and on the other \wrMissOther{}, which the reference calls deleted, one model read the code as edited and the other as unchanged. Of the \wrExclN{} sampled exclusions both models found \wrExclEdited{} edited and \wrExclDeleted{} deleted, so exclusion removes hard changed cases. Agreement statistics are in Table~\ref{tab:refaudit}; a blinded packet of 120 items with an answer sheet is prepared for two human annotators and has not been annotated.

\subsection{Parametric Copy Suite}
A held-out suite of \wpNMain{} constructed trials from \wpSources{} source files crosses 0, 1, 2, 4 or 8 pre-existing identical copies with the distance of the nearest one, anchors of 1--8 lines and the fate of the original; \wpNSame{} more trials let the revision itself add the copy (Table~\ref{tab:copysuite}). The deployed cascade missed \wpDepMiss\% of the changes. Distance decided the outcome and the number of copies did not: the guarded cascade missed \wpGiCOneMiss\% of changes with one copy and \wpGiCEightMiss\% with eight, and every miss of a guarded locator had a copy directly next to the original (\wpGiDAdjMiss\% for the cascade, \wpCmGiDAdjMiss\% for CodeMapper). AG requested a check on every original shifted by lines inserted directly above it (\wpAgFShiftExtra\%), AGi on none (\wpGiFShiftExtra\%); when the revision adds the copy, AGi missed more (\wpCmGiSameMiss\% against \wpCmAgSameMiss\% over CodeMapper; paired difference \wpSameDCmGiVCmAgMiss{} points, \wpSameDCmGiVCmAgMissLo{} to \wpSameDCmGiVCmAgMissHi). Grouped into issues of two to four anchors, \wpCmGiIssueMiss\% of issues went unreturned for CodeMapper+IG+AGi.

\subsection{Applied Review Suggestions in Five Languages}
A GitHub review suggestion quotes lines $O$ and proposes a replacement $S$; where they occur at the pull request's last head gives a reference no annotator made. We took \wkUnits{} suggestions from \wkPRs{} merged pull requests in \wkRepos{} repositories (Python, TypeScript, Go, Rust and Java): \wkClsApplied{} applied, \wkClsUntouched{} untouched, \wkClsRewritten{} rewritten, \wkClsGone{} deleted and \wkClsAmbiguous{} ambiguous; two independent classifiers agreed on every suggestion (Table~\ref{tab:suggest}). CodeMapper placed \wkCmQPlace\% of applied or untouched targets, the deployed cascade \wkDepPlace\% and GitHub \wkGhPlace\%. Every missed re-check of the cascade and of CodeMapper, guarded or not, came from applications that add lines around verbatim reviewed lines (\wkAppliedWrap{} of \wkClsApplied{}), which no quotation comparison can see; GitHub's flag, which follows the diff hunk, also missed rewritten and applied suggestions. No locator placed a target on wrong code silently. Asked whether the reviewer's concern was addressed rather than whether the code changed, two hosted models reached precision \wkBeamClaimPrecision\% and \wkNemoClaimPrecision\% and recall \wkBeamClaimRecall\% and \wkNemoClaimRecall\%, against \wkBeamDiffPrecision\%, \wkNemoDiffPrecision\%, \wkBeamDiffRecall\% and \wkNemoDiffRecall\% for the change question, but still called \wkBeamClaimFP{} and \wkNemoClaimFP{} of \wkLlmUntouched{} untouched suggestions addressed. Application is a proxy for an addressed concern, so this shows that the concern question predicts applied suggestions better on this sample, not that it helps supervisors; such an assessment may annotate a request but never resolve an issue.

\subsection{An External Benchmark: ReviewAnchorBench}\label{sec:rab}
ReviewAnchorBench \cite{fu2026reviewanchorbench} applies ten mechanical transformations to the files of public review suggestions written by bots, and records for each case the target file's hash and the oracle span and state. Its released packages do not contain the transformation builder, so we rebuilt each target from the pinned source file and the recorded parameters and accepted it only when its SHA-256 matched the released hash. Seven families rebuild exactly. The three that insert generated text (internal line edit, surrounding context edit, whitespace) do not, and the source files of \wrPopUnavailable{} and \wrHardUnavailable{} cases have since disappeared from GitHub. That leaves \wrPopCases{} cases from \wrPopAnchors{} anchors in the population-sampled stratum and \wrHardCases{} from \wrHardAnchors{} anchors in the hard held-out split (Table~\ref{tab:rab}); the protocol was frozen before any locator ran. Our CodeMapper run agreed with the benchmark's released CodeMapper output on \wrCmAgreeK{} of \wrCmAgreeN{} population cases (the same start line, or no location from either).

The layer cut missed re-checks over the deployed cascade from \wrPopDepMiss\% to \wrPopGiMiss\% (held-out \wrHardDepMiss\% to \wrHardGiMiss\%) and over CodeMapper from \wrPopCmQMiss\% to \wrPopCmGiMiss\% (\wrHardCmQMiss\% to \wrHardCmGiMiss\%), and removed every silent wrong placement of the deployed cascade (\wrPopDepSilentK{} and \wrHardDepSilentK{} cases). The benchmark's own cascade, which also searches for the reviewer's replacement, missed \wrPopRabMiss\% and \wrHardRabMiss\% on the seven families and \wrPopRabTenMiss\% and \wrHardRabTenMiss\% on all ten, re-scored from its released predictions. Its difference from the guarded cascade in missed re-checks lay within the repository bootstrap interval (\wrPopDGiVRabMiss{} points, $[\wrPopDGiVRabMissLo, \wrPopDGiVRabMissHi]$, population). Two mechanisms separate the approaches; both were tabulated after the first summary was read (amendment~1). The copy guard flagged \wrPopGiMoveCopyReq{} of \wrPopGiMoveN{} moved blocks (held-out \wrHardGiMoveCopyReq{} of \wrHardGiMoveN), because a moved block's text existed in the old file at its old position; this produces most of the layer's \wrPopGiExtra\% unnecessary requests, against \wrPopRabExtra\% for the benchmark's cascade. On duplicated pre-images the locators placed the target on the original lines, almost always without a request (\wrPopGiDupOrig{} of \wrPopAnchors{} and \wrHardGiDupOrig{} of \wrHardAnchors{} for the guarded cascade), whereas the benchmark counts only abstention as correct. The file-pair diff does identify the original, so the placement is defensible, but a copy the revision adds is invisible to the guards, as the parametric copy suite found.

\subsection{Supervisor Interventions in Ten-Commit Chains}
On the \wvChains{} archived chains (Section~\ref{sec:prefixes}) a simulated supervisor acts at commits 1, 2, 3 and 5, only on a request: P1 corrects a wrong or lost anchor to the reference location, P2 accepts a correctly placed \lbl{changed} anchor as reviewed, P3 does whichever fits, and P4 dismisses the issue at the first request (Table~\ref{tab:interventionsfull}). With no action the stored cascade traces were reproduced exactly (\wvGateMismatch{} mismatches), and CodeMapper's on \wvGateCmAgree{} and, with the identity rule, \wvGateCmIdAgree{} of \wvGateCmHops{} hops, since CodeMapper is not fully deterministic. Correction raised the deployed cascade's correct endpoints by \wvDepDPOneCorrectAbs{} (95\% chain-bootstrap interval \wvDepDPOneCorrectAbsLo--\wvDepDPOneCorrectAbsHi) with \wvDepPOneAct{} actions but removed only \wvDepDPOneWrongAbs{} of \wvDepPZeroWrong{} wrong endpoints, because most of its wrong placements raise no request. Without the identity rule, acceptance lowered missed changes by exactly the changes it reviewed (\wvDepDPTwoMissAbs{} and \wvCmDPTwoMissAbs); with the rule it removed \wvDepIdDPTwoReqAbs{} and \wvCmIdDPTwoReqAbs{} later requests with missed changes unchanged. Dismissal ended between \wvDismissedMin{} and \wvDismissedMax{} chains per method, of which \wvDismissedChangedMin{} to \wvDismissedChangedMax{} had a later change that the dismissed issue never surfaces.
