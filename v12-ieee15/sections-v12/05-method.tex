\section{Evaluation Method}\label{sec:method}

\subsection{Populations}
\textbf{Controlled edits.} Every Python file of 60--1,500 lines in the portal's backend and a partner team's tracer (\nFiles{} files, \nLines{} lines) was exported from fixed commits. A trial picks a 1--10-line anchor with a unique quotation and applies one of twelve edit operators (shift, re-indent, moves within and between files, duplication above, token edits, rewrites and deletions), each of which supplies the reference outcome; there are \nPerOp{} trials per operator and seed, on seeds \seedMain{} and \seedRep. They are text mutations, not necessarily valid programs.

\textbf{Real histories.} We formed pairs of consecutive commits and pairs ten commits apart in nine Python projects: four of our own (\rOwnCommits{} first-parent commits) and Requests, Flask, Click, HTTPX and Rich (\rOssCommits{} commits by \rOssAuthors{} contributor names). Anchors are statements of 1--10 lines in function bodies of files the later commit changed, drawn as a \emph{uniform} sample and an \emph{edit-targeted} sample overlapping a diff hunk; \rN{} observations from \rPairs{} commit pairs were retained. Source was parsed, never executed.

\textbf{Student-authored repositories.} As a stand-in for student code we selected \hTwoRepos{} public Python repositories describing themselves as capstone, senior-design or course projects, by a frozen search and screening protocol (team authorship, at least 2,000 lines and 60 first-parent commits), yielding \hTwoN{} observations (\hTwoTargetedN{} edit-targeted). They are student work but not supervised resubmissions, so they show technical feasibility on code students write, not educational effectiveness. No threshold was chosen on them; the corrected copy guard AGi was specified after the first copy guard's results on them had been read, so for AGi they are not held out.

\textbf{Human-annotated benchmark.} The public CodeMapper benchmark \cite{hu2026codemapper} provides \cExtHumN{} code regions whose later locations were annotated by people, in several languages, in two sets with manually (A) and automatically (B) chosen source regions (``Human A/B''), plus tool-derived histories (\cExtExtN{} regions in all). It is the only reference here whose labels people made independently of the authors; the suggestion oracle below uses externally authored data but our classifier. \sys{} sees each case as a file pair, so cross-file recovery is not exercised.

\textbf{Held-out stress seed.} Constructed indentation, duplicate-copy, short-anchor and compound-edit suites (\wiFrN{} cases) were generated after the safety-layer protocol was fixed. In the indentation suite every file parses and an edit counts as behavior-changing when the syntax tree of the enclosing scope changes; compound cells compose up to four operators. Their rates describe constructed cells, not prevalence. A parametric copy suite, generated under its own frozen protocol, crosses the number and distance of pre-existing copies with anchor height and the fate of the original (Section~\ref{sec:copysuite}).

\textbf{Applied review suggestions.} GitHub review suggestions in five languages give a reference that no annotator made: where the quoted lines and the proposed replacement occur at the pull request's last head decides whether the target was changed and where it is (Section~\ref{sec:suggest}).

\subsection{Reference for Real Histories}\label{sec:oracle}
Real-history references come from Python's abstract syntax tree. Functions are identified by qualified name and their body statements are aligned by normalized trees; equal statements give the new location, a statement in an equal-cardinality replacement is paired with the statement of the same type at the same offset, and a deleted target can be found as a unique equal tree elsewhere. Ambiguous cases are excluded for every method (\rExcludedPct\%). A recorded in-house audit of 40 decisions accepted 39; it is not blinded.

\emph{Blinded adjudication.}\label{sec:refaudit} Two hosted models, not people, re-decided \wrAllN{} stratified targets (plus \wrExclN{} excluded candidates) blind to the reference and to every method, from the old excerpt with the reviewed lines marked and the paired new file (Table~\ref{tab:refaudit}). They agreed with the reference on \wrPairBeamStatus\% and \wrPairNemoStatus\% of the targets decided by same-type pairing, the step that decides \refdirPaired{} of the \refdirChanged{} changed targets, and on \wrAlignedBeamStatus\% of the aligned controls. Agreement was lowest where the reference relocates code to another file, which the input does not show (on targets where the methods disagree, \wrDisBeamStatus\% and \wrDisNemoStatus\% overall but \wrDisWithinBeamStatus\% and \wrDisWithinNemoStatus\% of the \wrDisWithinN{} kept in the file), and where it reports a deletion: of the \wrDelWithinN{} deletions and relocations inside the paired file, both models contradicted the reference on \wrDelWithinSuspect{}, and on \wrDelWithinEdited{} of them they found the code edited rather than deleted. Both readings are changes, so this error moves placement, not missed re-checks. On the deployed cascade's \wrMissN{} misses the models agreed with the reference on \wrMissBeamStatus\% and \wrMissNemoStatus\%, and both contradicted it on \wrMissSuspect{}: on \wrMissLowering{} both called the code unchanged, which would lower the miss count, and on the other \wrMissOther{}, which the reference calls deleted, one model read the code as edited and the other as unchanged. No reading raises the count. Of the \wrExclN{} sampled exclusions, both models found \wrExclEdited{} edited and \wrExclDeleted{} deleted, so exclusion removes hard changed cases. Two models agreeing against the reference is evidence of a reference error, not proof; a blinded packet of 120 items is prepared for human annotation.

\emph{Direction of reference error.} The reference calls a target unchanged only when its quoted lines stand verbatim, ignoring whitespace, at the reference location; all \refdirCertified{} real-history targets it called unchanged pass this check. That shows the text there is unchanged, not that it is the reviewed code. All but \refcopyRelocated{} of these targets stay aligned or paired in their own function; those \refcopyRelocated{} left it and were placed on the unique equal statement elsewhere, and in the public histories \refcopySuspect{} of the \refcopyChecked{} checked landed where an identical statement already stood, so the reference may have taken a copy for the reviewed code; the deployed cascade requested no check on them. Counted as hidden misses, they raise the deployed miss rate from \refdirMissPct\% to \refcopyMissPctChecked\%, and with the \refcopyUnavailable{} unchecked relocations in our own projects to \refcopyMissPctWorst\%. Conversely, of the cascade's \wpaMissTotal{} misses \refdirMissAligned{} rest on an equal tree, \refdirMissPaired{} on pairing and \refdirMissDeleted{} on a deletion; if every pairing and deletion behind a miss were wrong the rate would fall to \refdirBoundPct\%. The bounds do not cover placement accuracy or unnecessary re-checks. The student repositories use the same reference.

\subsection{Locators}
Three conventional policies reimplement documented review behavior: \emph{fixed line} keeps the original span, \emph{diff drift} follows equal diff blocks, and \emph{exact quote} searches the same file for the nearest stripped quotation. \emph{Cascade v1}, an earlier internal version, searches other files before fuzzy matching, searches the whole file and uses $\theta=0.75$. The \emph{contextual tracker} is a pinned third-party implementation in the style of LHDiff \cite{oselvarlhdiff}, with its defaults; \emph{CodeMapper} \cite{hu2026codemapper} and GumTree \cite{falleri2014fine} are run from pinned releases. Two \emph{language models}, \wjModel{} (the model the deployed portal is configured with) and \wjNemoModel{}, act as locators at temperature~0: each receives the old region with 15 lines of context and the complete new version of the paired file, and returns where the region now is and whether it changed. Only public code was sent to the models. Any locator's window can pass through the cascade's quotation comparison (\emph{labels only}: \lbl{content-match} or \lbl{moved} when the normalized quotation is found unchanged, \lbl{changed} otherwise, \lbl{removed} on no match) and then through IG+AGi; the guards never move a window.

\subsection{Outcomes and Statistics}\label{sec:safety}
For a set of targets, let $C$ be those whose code was edited or is gone, $P$ the content-preserved ones, $S$ the surviving ones, $A$ all targets and $W\subseteq A$ those placed at a wrong location, and let $R=\{\lbl{changed},\lbl{removed}\}$ be the labels that request re-check. Then
\begin{align}
\text{missed re-check} &= |\{c\in C : \ell(c)\notin R\}|\,/\,|C|,\label{eq:missed}\\
\text{false re-check} &= |\{p\in P : \ell(p)\in R\}|\,/\,|P|,\\
\text{silent misplacement} &= |\{x\in W : \ell(x)\notin R\}|\,/\,|A|,
\end{align}
and the lost rate is the share of $S$ with no location. Tables abbreviate these as Miss, Extra and Silent, and add \emph{Misdir}, the share of all targets placed on wrong code \emph{with} a request; it includes deleted code relocated onto other code, which requests a re-check but points the supervisor at the wrong place. Placement (file and start line on surviving targets) and classification are scored separately, because a location can be right while its change status is wrong. The extended report lists every rate with its denominator. All safety outcomes are \emph{label} safety: whether a request fires when the quoted code changed, not whether the reviewed concern is affected.

Synthetic proportions use Wilson intervals \cite{wilson1927probable}. Real-history observations share commit pairs and projects, so we report fixed-seed cluster-bootstrap 95\% intervals over commit pairs or projects for headline rates and every paired difference, and state a direction only when the cluster interval excludes zero. Paired outcomes are also tested with the exact McNemar test on discordant pairs \cite{mcnemar1947note}. The \rN{} real-history rows contain 234 repeated targets across the two samples. Many secondary comparisons are reported without multiplicity adjustment and should be read as such.

\subsection{Protocols and the Strength of Each Result}
Every analysis added in this revision followed a written protocol whose text and code hashes were recorded with a timestamp before it ran, and every amendment before the outcomes it concerns; these are local records, not external preregistrations. A protocol that precedes an analysis need not precede exposure to its data: the re-aggregations, strata, identity-floor replay and policy selection read records whose outcomes had already been seen, and stay tier E1. A reproduction gate first required per-observation agreement with all \nTrialsAll{} archived controlled trials and all \smRealCasAccN{} real-history observations. Table~\ref{tab:evidence} assigns each result to one of five tiers of evidential strength, and the text names the tier of every claim. The language-model study registered its prompt, settings, populations and hypotheses before any evaluation call: \textbf{J1}, the layer lowers the model's missed re-checks, and \textbf{J2}, its silent misplacements, each judged by the paired cluster interval, with exact paired tests and Holm's adjustment as a secondary check.
