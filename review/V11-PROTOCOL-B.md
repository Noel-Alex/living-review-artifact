# V11 B1 frozen refinement protocol

This is a timestamped local protocol, not external preregistration. `evidence/v11-wpb1/protocol-freeze.json` records this document's SHA-256, UTC freeze time and executable source hashes. That record must precede the gate and evaluation start records. Frozen executable files must remain byte-identical. A later correction requires a separately named post-hoc run, preserving both outputs and explaining the deviation.

**All 15,064 real-history observations, internal and public, were inspected in earlier revisions, and AG was designed from the 37 archived missed re-checks. Variant results on every one of these histories are retrospective.** The genuinely held-out evaluations of these frozen variants are controlled seed 2 with the new B1a/B1b operators generated after this freeze, the CodeMapper human-annotated datasets (WP C), and the student-repository corpus (WP H). These later datasets are not executed or claimed complete by WP B1.

## Frozen algorithm

Inputs are the anchor, complete later-version file map `(path -> hash,text)`, previous anchored-file text and previous-version file texts. These are already available to deployed `carry_forward`, which loads previous-version files; AG requires no new external input. Source is read/parsed, never executed. The unchanged `_lines`/`_runs` and `expected_start` semantics come from pinned `carry.py`, extracted through WP A's loaders. Nonempty lines are stripped for matching, and blank lines may be skipped in an exact run.

All switches off reproduce tier 1 file hash, tier 2 same-file normalised match nearest the original start, tier 3 local fixed-height fuzzy search, tier 4 cross-file normalised match in sorted path order, else removed. Same-file exact ties use earliest enumeration. Tier-3 radius is `max(10,2*s)` around the diff-predicted start, not the anchor origin. Hash equality returns the original range and exact label without guards.

**IG.** For accepted tier-2/tier-4 runs, retain nonblank lines only and measure each leading-whitespace width after `expandtabs(8)`. Let `b=width[0]` and `relative[i]=width[i]-b`. Compare quotation and returned run. For Python paths (`.py`, `.pyw`, case-insensitive), a base or relative-profile difference changes the label to `changed`, requests re-check, and adds sub-reason `layout`. For other languages, only a relative-profile difference does so. Coordinates are unchanged. Blank lines and trailing spaces alone do not alter this profile. Tab/space forms with equal expanded width are equal. IG is a conservative layout signal, not an AST-equivalence test.

**AG.** Compute `expected_start` on the anchored file's old and new text. At tier 2, if a normalised run starts exactly at that predicted index, prefer it; otherwise retain the deployed nearest-origin choice. For a selected tier-2/tier-4 exact-text run, define `at_expected = candidate_path == anchor_path and candidate_start == expected_start`. If false, count all normalised runs (including overlaps) in the candidate file's previous and later texts. If the previous candidate file is missing, treat the run as newly introduced. Otherwise a clean move requires `new_count > old_count`. If not, retain coordinates, give label `moved`, set the proposed explicit re-check flag, and add sub-reason `pre-existing-copy`. Tier 4 is always outside the predicted location in the original file. IG can subsequently override the label to changed while retaining both reasons. AG is not implemented by pretending that every moved label now requests re-check; only its flagged cases do. Count growth is evidence of introduction, not proof of original identity: simultaneous new duplicates can still defeat it.

**VW.** Replace tier 3 only. For anchor height `s`, set `d=max(1,ceil(s/2))`. Enumerate full windows of height `h` from `max(1,s-d)` through `s+d` within the same radius around the diff-predicted start, bounded separately by each height's fit in the file. Compare `' '.join(nonblank stripped quotation lines)` to the equivalent joined window using `SequenceMatcher(...,autojunk=False).ratio()`. Maximise ratio; ties minimise distance to predicted start, then `abs(h-s)`, then start index, then height. A positive best ratio at least theta returns label changed and the chosen full range. Otherwise continue to tier 4. Optimisation may use upper bounds and cached candidates only without changing these choices.

Run all eight IG/AG/VW combinations at theta 0.85 and 0.55. Theta 0.85 is the actual deployed default. Theta 0.55 is fixed from WP A's leave-one-project-out accuracy calibration, selected in every fold; no new selection or constrained calibration is performed. Empirical safety constraints previously failed to transfer to public data and are not guarantees.

## Inputs and construction truth

Pinned corpus, Git heads, archived observations, source-context references, existing tracker binary and reused scripts are SHA-256 identified in the input manifest. Use the original controlled corpus and anchor sampler for B1a and duplication trials. Preserve the original unrelated-file sampling (up to 25) where applicable. Sampling uses replacement; report unique accepted indentation constructions. File maps and old-file texts are shared between methods, with no oracle path supplied to the cascade. Original line/diff/exact-quote baseline rename handling follows WP A. The external contextual tracker is the unchanged existing binary, not canonical LHDiff; its declared re-check adapter is WP A's.

B1a uses at least 300 accepted trials for each of eight operators per seed. The original sampler is rejection-sampled for applicable constructions. Both files must parse with `ast.parse`. No edit changes nonblank stripped quotation text. Multiline string-literal lines are excluded. A semantic construction is retained only when both the enclosing-function/module dump and whole-module dump change; a layout construction only when both remain equal (`include_attributes=False`). The enclosing scope is the smallest function covering the full anchor, or the module. This is construction plus syntactic AST truth, not execution equivalence or human concern validity.

Dedent-out shifts the anchored run out one four-column level. Absorb shifts it one level into a preceding block when parsing permits it. Inner-relative changes exactly one nonfirst nonblank anchor line by four columns. Nest-shift requires an entire compound header/body node at the anchor start and shifts that run one level deeper/shallower in existing code. Continuation re-aligns a nonfirst line lexically within brackets; blank-lines inserts/removes an interior blank; trailing-space adds trailing spaces; tabs-spaces replaces eligible leading widths by tabs plus residual spaces. Parse failures, unsuitable samples and wrong-AST-class candidates are separately counted; a 200,000-attempt cap reports an incomplete cell rather than hiding it.

The original twelve operators retain their original truth/scoring. Separately audit all original `reindent` trials for old/new parseability, module and enclosing-scope AST change, and their deployed labels/re-checks. Do not silently relabel historical results. If a parseable AST-changing reindent was scored unchanged by v10, state that it weakens the unchanged-success interpretation.

B1b duplicates cross five copy positions (near/far above, near/far below, another file) with five original fates (unchanged, token edit, deleted, moved far in file, moved to another file), at least 150 trials per cell per seed. Identity is tracked by construction tags, not textual identity. Near means final start-to-start distance at most ten lines: choose insertion gap `0..10-span`. Far means at least forty lines. Same-file far movement also requires at least forty lines. Another-file copies/moves have explicit distinct destination paths. Duplicates need not parse, matching the original controlled benchmark's textual-edit setting; they are not AST-semantic evidence.

Short anchors use all eligible noncomment one-line source anchors, stratified by within-file stripped-text recurrence (1, 2–3, at least 4) and lexical word/punctuation count (1–3, 4–6, at least 7, with `\w+|[^\s\w]`). Sample a file then a target in that file/stratum. Preserve original operator bounds (start at least twenty lines into a file with eleven lines following). Run each of the original twelve unchanged operator functions at least 150 times per frequency × token bin × operator per seed. Record typical target categories and any unavailable/incomplete cells. Token-count bins are descriptive, not a language parser. Original truth here is textual construction, with the same original-reindent caveat.

## Outcomes, hypotheses and analysis

Primary outcomes are placement correctness (file/start, and all-target correctness including correct absence separately), changed/gone missed re-check rate, wrong-and-silent placement rate, and added re-checks per 100 preserved-reference anchors. Secondary outcomes include labels/confusion, wrong placement, lost/manual-search, false re-check, AST-changing false-unchanged on B1a, and exact file/start/end range recovery. Use WP A's `events`, denominators and Wilson intervals; substitute the explicit proposed AG re-check flag only for workflow-request metrics. Native-label classification remains separate. Earlier adapter semantics (`label != exact`) are reported separately and need not agree with a proposed explicit flag.

Evaluate v7 range metrics only on the identical declared surviving AST-reference subset; report missing/ambiguous references and gone targets separately. Never infer an end line for line-only comparators. Generated stress ranges come from construction. Real quote-window-preserved targets can still have AST/context differences: additional requests are workload cost under that reference, not necessarily unnecessary requests. AST-identical B1a is the cleaner false-request measure.

Hypotheses: (1) normalisation hides parseable indentation AST changes, including potentially some original reindents; IG should detect them but may request inspection for AST-identical continuation layouts. (2) AG should reduce retrospective archived misses and wrong-silent placements, but can miss simultaneous copy-introduction ambiguity and can increase requests for preserved text. (3) VW should improve changed-height recovery but can increase false relocation or hurt start placement. Report adverse effects and interactions; do not select only the best combination.

Report each seed, operator/cell and real internal/public, sampling scheme, project and horizon. On primary suite-level and real group/sampling strata, use exact two-sided paired binomial tests on discordant outcomes and 10,000 paired cluster-bootstrap resamples (seed 20261031): real by commit pair, controlled by source file. Resample clusters with replacement, retain all their observations, and form paired rate differences from pooled counts/denominators. Undefined zero-denominator resamples are counted. Comparisons are against the all-off cascade at the same theta and additionally the actual theta-0.85 deployment. Intervals/tests are nominal exploratory summaries, with no familywise or causal generalisation claim.

For every combination report gross added, spared and net requests per 100 content-preserved references, relative to all-off at the same theta. Also give single-switch costs for IG, AG and VW; no cost is measured faculty time. Report guarded costs on AST-identical B1a separately. Report results on exactly the archived 37 misses and 40 wrong-silent cases, with case-level coordinates, labels, request flags and reasons. This is explicitly retrospective mechanism analysis, especially for AG. Also audit normalised-equal/indentation-different deployed returned spans and oracle-assigned surviving spans in complete histories, retaining oracle classes, labels and AST relations without inventing human semantics.

Deliver machine-readable JSON, generated TeX and `review/V11-WPB1-RESULTS.md`, with the three main findings first, limitations, protocol deviations, commands and paths.
