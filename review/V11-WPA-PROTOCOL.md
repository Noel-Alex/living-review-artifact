# WPA analysis protocol

Frozen before new matcher/factorial public-history results. This is a local exploratory protocol, not external preregistration. Only WPA-permitted paths are writable; Python runs with bytecode disabled. The runner records this file's SHA-256 in each output.

- Reconstruct the controlled trials from both archived RNG seeds and pinned source. Compare every archived non-timing method outcome, silent/flagged field, metadata, and final label. Reconstruct real inputs from pinned histories and compare each method outcome/silent field, default label, and all archived final/v1 threshold outcomes. New parameterised results remain quarantined until the complete gate passes. Tracker reruns, if used, must match every saved outcome including execution errors.
- Metrics: report original all-target correctness (correct absence included), surviving file/start accuracy, coarse content-state classification (preserved/edited/gone), and full output-label by five reference-class confusion counts. Exact/moved predict preserved; changed predicts edited; removed predicts gone. No claim of semantic classification or unique mapping of four labels to five reference classes. Errors remain a separate output class and contribute no correct outcome.
- Workflow re-check is changed/removed. Baseline labels are adapters: fixed-line and diff drift return removed on no-match, otherwise exact/moved with no native request; exact quote requests only on no-match under workflow semantics, while its historical displacement flag is retained separately. V1 labels are reconstructed from the branch used. Tracker has no native lifecycle policy; if coordinates are recovered, a declared adapter compares the original-height normalized quote at its mapped location (changed on difference, exact/moved on equality, removed on completed no-match, execution_error on failure). Execution failures require inspection, remain unsuccessful, and are not counted as successful lost/no-match. Native tracker safety is unmeasured.
- Missed/false rates use changed-or-gone/preserved denominators. Wrong and wrong-without-recheck use all targets, with conditional returned-location variants available. Lost uses surviving targets; all-target lost incidence is also retained. Effort sums all five event indicators per all-target anchor, allowing missed and misdirected events to overlap as the brief specifies. Normalize lost cost to one; other four weights independently take five logarithmically spaced values: wrong-with-recheck 0.1--10, silent wrong 1--100, missed 1--100, false re-check 0.01--1. This is sensitivity analysis, not measured reviewer effort. Tracker execution-error effort cannot be inferred from the five-term model: report a separate inspection-cost sensitivity and exclude it from primary dominance comparisons if any failures occur.
- Factorial: fuzzy-first/cross-first, local/whole-file, thresholds 0.50--0.95 in 0.05 increments. V1's forced partial window when the file is shorter than the anchor is an additional full-height/legacy-partial factor for whole-file search. The factor is inert for local search. Other input-domain differences (empty quote/hash and span fallback) are documented and audited; no extrapolation outside nonblank valid benchmark anchors. Compute exact runs and maximum fuzzy candidates once per input, preserving ascending ties and SequenceMatcher with autojunk disabled; cell evaluation only changes order/threshold. Compare the deployed and v1 corners against direct pinned functions for every observation before using the grid.
- Cluster percentile bootstrap: 10,000 draws, fixed seed 20261031, sample clusters with replacement and retain every observation in each selected cluster. Controlled: source file. Real: commit pair and separately project. Same draws for paired methods; ratios use resampled anchor denominators. Retain repeated observations. Per-project contrasts and sign counts accompany pooled contrasts. Project intervals with few clusters are descriptive and do not establish course-level generalization.
- Calibration: leave one project out, select using all anchors of the other projects (existing accuracy objective); separately search only deployed-order/local/full thresholds and the full grid. Ties favor stricter thresholds, then deployed policy, full-height windows and local scope in that order. Also report edit-targeted selection sensitivity. Safety-constrained selection uses only internal edit-targeted anchors for objective and constraints (missed among changed/gone; gone-present among gone); maximize accuracy subject to the requested alpha/beta grid, then apply once to public data. Report infeasibility and compare existing theta 0.5. The full-grid selection is retrospective; public histories were previously inspected in earlier revisions.
- Regenerate exclusions with instrumented original selection/oracle AST, preserving RNG order and decisions; gate ordered retained rows and every exclusion-reason count. Record all attempted sampled observations with pair/horizon, anchor height, file diff added+deleted line count, hunk counts/sizes and reasons. Diff bins are 0, 1--10, 11--50, 51--200, >200 changed lines in the corresponding file. Excluded cases have no invented outcomes or human labels.
- Rounding: recompute controlled outcome partitions and all other displayed percentage partitions for which raw mutually exclusive counts exist; independent accuracy columns are not partitions. Use ordinary independent one-decimal rounding, show raw counts, and explicitly allow totals of 99.9/100.1. Verify archived threshold rows and their class denominators directly.

Protocol deviations, gate failures, incomplete work and unavailable data must be recorded explicitly in the results note. AGENTS.md is intentionally unchanged under the direct instruction prohibiting its modification.
