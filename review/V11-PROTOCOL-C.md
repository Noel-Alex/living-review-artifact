# WP C frozen evaluation protocol

Local prospective protocol for the independent CodeMapper datasets. All existing Living Review histories and construction seeds are retrospective. No method has been run on a CodeMapper dataset, or on GumTree/CodeMapper benchmark outputs, before this document's freeze record. Schema inspection, documentation, dependency installation and synthetic adapter tests are permitted before freeze. The B1 variants remain exactly the earlier frozen code; every evaluation invocation rechecks every hash in `v11-wpb1/protocol-freeze.json` and its protocol hash. No threshold or variant is selected using the new annotations.

## GumTree adapter (same-path file pairs only)

Use GumTree's default matcher (the distribution's registered default), Simplified Chawathe actions, and bundled tree-sitter-ng generators. Python frontend: `python-treesitter-ng`, tree-sitter binding 0.26.6, Python grammar 0.25.0. Use the explicit tree-sitter generator for supported other languages (Java, JavaScript, C#, C++, Go, Ruby, TypeScript, PHP); HTML and non-supported extensions are unsupported execution outcomes, retained separately and in all-target reporting. Java 26.0.1 is used if the synthetic smoke succeeds. Per file-pair matching timeout: 60 seconds. No retries for semantic parse/match errors. Each timeout kills/restarts only the owned isolated worker. Parse-error nodes are failures, including tree-sitter recovery trees; do not accept a malformed file as valid syntax.

Select **all positive-length old AST nodes** whose full source-line extent lies within the inclusive anchored lines. If none exist, choose the smallest positive-length node covering the entire anchor, breaking ties by preorder. Map selected nodes with GumTree's mapping store. Returned lines are the min start and max inclusive end of their mapped counterparts. No mapped counterpart means removed. Convert GumTree UTF-16 positions to Unicode line coordinates without treating byte offsets as characters. Ignore zero-length synthetic nodes.

Changed if an update/insert/delete/move action affects a selected old node or its subtree, or a mapped new node or its subtree. Tree-level actions touch their entire subtree. An inserted node directly under a mapped selected node touches it. An action on an unrelated ancestor is not by itself an edit to every descendant (except subtree delete/insert). A move of a selected node or its ancestor affects the selected node and requests re-check. Otherwise mapped at a different start is moved, and mapped at the old start is exact. Removed requests re-check; parse/match failure is inspection-required but not a successful removed result.

Never provide an oracle target path to GumTree. A missing same-path new file is a completed no-match; a cross-file surviving reference is scored unsuccessful even if the tool returns absence. Report all-target and same-file-reference subsets, separately retaining deletions and same-path file absence. Same-file-only removes surviving cross-file references using truth solely for scoring.

## CodeMapper adapter

Default 15 unchanged context lines on each side; all four technique-disable flags false; native Levenshtein selection with no threshold. CodeMapper is a mapping tool only, with no review-state model. For line-anchor tasks supply full old lines: one-based inclusive `[start_line,1,end_line,last_content_character]`, with explicit zero-column/end-line handling consistent with its `get_region_characters`. For its independent data supply its original character region unchanged.

Use immutable Git objects to replace only the force-checkout file-reading boundary, preserving UTF-8 then Latin-1 fallback and universal-newline decoding. Git commands are read-only argument vectors, with the original diff algorithms/flags preserved. The wrapper rejects shell metacharacters and arbitrary commands. Resolve target path without labels: same path if present; otherwise use Git's source/target rename detection (`-M`), else deleted. This deterministic safety adaptation differs from upstream's history-based force-checkout resolver; report it as an adapter limitation, and record whether it changes published reproduction. No expected target range, class, operation or text reaches mapping code.

Controlled trials use two-commit repositories under WP C evidence, with the original source filename(s) and unchanged input texts. Do not force the true moved file into CodeMapper; its normal file-level scope is retained. Real histories use pinned clones read-only. Timeout 60 seconds per anchor including Git calls, measured with a killable isolated Python process. Cache file-pair diffs within a process only; report cold per-anchor wall time, and separately any amortized cached time. Empty or malformed outputs are failures unless the native output explicitly denotes deleted or the label-free path resolver establishes file absence. Output character range maps to inclusive first/last occupied line. Change label is exact if mapped region text equals the original source region text, otherwise changed; no native moved label is invented. Deleted maps to removed. All altered adapter behavior is disclosed.

## Living Review methods on independent data

Run deployed cascade (theta .85), cascade v1 (archived .75), exact quote, diff drift, fixed line, the existing contextual tracker and **all 16** B1 combinations (IG/AG/VW switches at .85/.55). The combined .85 and .55 variants are both reported, with .85 the primary frozen combined comparator. No retuning. Verify frozen hashes before each run/batch. Preserve AG's explicit recheck flag (which can be true with moved label); report workflow-policy rates using that flag and earlier adapter semantics separately.

The cascade consumes line anchors, not arbitrary character spans: expand original character ranges to occupied full lines, keeping source/target paths and source byte content. A region ending at column zero excludes that last line. Supply full project file maps when available; if only paired files can be acquired, label restricted-input results separately and never treat them as full-project comparisons. IG keeps its frozen language extension rule; do not adapt it to non-Python outcomes. Line-only comparator outputs are projected to the original anchor height (clipped at EOF) **only for external character metrics**, with this projection explicitly identified; do not claim native end recovery. Cascade/variant native full ranges and GumTree native mapped ranges are expanded to full-line character bounds. CodeMapper keeps its native arbitrary-character boundaries. Report region-granularity handicap; do not trim predictions using truth columns. Missing mapping scores zero when ground truth survives. Correct explicit deletion earns exact/precision/recall/F1=1 as upstream does. Failures earn zero, including on deleted truth.

## Outcomes, inference and reporting

WP A metrics: all-target correct location/absence; surviving path/start; reference-class by output-label confusion; missed re-check among edited/gone; false re-check among preserved; wrong, wrong-silent and lost. Baseline no-match requests inspection; fixed-line/diff/quote acceptances do not. Tracker compares normalized source-height quote at returned line. Also report native text equality (CodeMapper) versus AST-action (GumTree) semantics; none constitutes semantic concern truth. For independent data derive preserved/edited only from annotated region text equality, with annotated deletion separate; annotation categories are not human labels of a review concern. Report raw counts and Wilson 95% intervals.

V7 exact path/start/end uses the identical surviving unambiguous AST subset from saved v7 source coordinates. No end is invented for line-only comparators. On controlled truth use construction start/end, clearly separate from AST-derived extents. CodeMapper external metrics reproduce upstream coordinate and rounding conventions in a named `upstream` view, including its longest-common-substring overlap score and inclusive absolute-index implementation. Additionally report ordinary positional character intersection without that implementation's offset quirks. Exact-match rate requires exact path and arbitrary-character boundaries. Character distance is sum of endpoint distances conditional on partial overlap; macro precision/recall/F1 include all rows with failure=0. Report each dataset and each language; classify language by the source file's actual extension, with documentation/configuration kept separate from the repository's nominal language. Report nominal language additionally if available from the artifact.

Paired contrasts compare GumTree and CodeMapper to deployed and combined B1 (.85 and .55) on all targets and identical subsets. Two-sided exact conditional paired-binomial tests retain discordant counts. 10,000 fixed-seed (20261031) paired cluster bootstraps: controlled clusters source file; real clusters commit pair; external clusters repository+commit pair. Nominal exploratory inference, no multiplicity-corrected superiority claim. A tool wins a stratum only by its measured outcome; no presumption of cascade superiority.

Draw at least 60 real-history GumTree/oracle disagreements with seed 20261031, stratified by reference class, sampling group and error kind (wrong location, lost, error). If fewer than 60 exist, include all and state the count. Sampling weights/counts remain in a separate key. The blinded packet matches the existing format: full old/new same-path source, old anchor, immutable revisions, local history, blank reviewer CSV; **no predictions, expected answers, oracle class or stratum in the packet**. Keep the key outside the packet. No human adjudication is performed or claimed. The real oracle itself uses Python AST statement alignment, so agreement shares syntax-based construction and does not independently validate concern identity.

## C6 amendment: matcher-independent safety and within-file hybrid

This amendment is registered after C1–C5 completed and after their results were inspected. All C6 analyses are therefore retrospective/exploratory, including CodeMapper data; they are not a new held-out evaluation. The exact preceding C1–C5 byte segment remains immutable at SHA-256 b5af90afd37561f29c76ad87a7585d33e31adfe7d89ad7de57bd8ce3e639d2ac. `c6-protocol-freeze.json` records its byte length/hash, the amendment-only hash, the combined-file hash and the UTC freeze time before any C6 evaluation. Its C1–C5 completion pointer must pass. No earlier freeze record is modified.

### Fixed methods and safety transfer

Evaluate GumTree, native-readonly CodeMapper, the contextual tracker strictly within the original path, and a hybrid using that tracker followed only on completed no-match by deployed cascade tier 4 (cross-file exact). A tracker execution error remains an error, not an opportunity to fall back. If the source path is absent in the new map, strict same-path tracking returns completed no-match. A saved rename-adjusted tracker output is reused only when its returned path is the original path; other required tracker calls use the same pinned executable. The hybrid may use only the saved deployed cross-exact result, or the identical pinned cross-file tier when no saved deployed result is available. It cannot use an oracle target, another cascade tier or a lower threshold.

Locations and native ranges are not reranked by the safety layer. Four fixed layer versions are reported for each matcher: quotation only, +IG, +AG, +IG+AG. Normalize a window as the tuple of stripped nonempty lines, exactly as B1. The source quotation is the full occupied old anchor lines. A mapper with native line range uses that complete returned range; line-only tracker uses original height clipped at EOF, explicitly marked as a safety-window projection rather than native range recovery. CodeMapper's character boundaries remain separately retained; C6 tests its line-expanded workflow window and never trims a prediction to annotation columns.

For a completed location, equal normalized quotation/window means exact/content-match at the old path/start, otherwise moved/content-match; unequal means changed. Completed no location means removed. Failures remain execution_error and inspection-required. Baseline changed/removed and all errors request re-check.

Apply the frozen B1 post-selection guard predicates verbatim, without changing frozen files. For a normalized-equal location, AG computes expected_start from the same pinned diff function on the original path, and counts old/new copies in the returned file using frozen runs. If candidate differs from original path or zero-based start differs from expected, and old candidate text exists and new_count <= old_count, retain moved and request re-check with pre-existing-copy. No unavailable old file is replaced with a fabricated zero. IG uses the frozen profile: Python .py/.pyw compares base and relative indentation, other languages relative indentation only; a mismatch changes the label to changed and requests re-check. AG is applied before IG as frozen. These guards do not relocate the underlying matcher; B1's candidate-selection preference cannot be applied to an already fixed location and is explicitly outside this transfer. No VW change or threshold tuning is introduced.

Preserve every error and interrupted attempt; resume only missing IDs. No missing-object repair may change pinned inputs or algorithms.

### Outcomes and fixed interpretation

Report the complete WP A metric family, Wilson intervals, label confusion, explicit re-check policy and raw failure counts by suite/operator, real sampling group/project, external dataset and actual language. Report human A/B non-Python separately from Java-derived records. Layer-only variants must preserve placement/range and character-mapping scores exactly. Keep lost among survivors, missed among edited/gone and wrong-silent among all targets. The hybrid is allowed to alter placement only by the registered cross-exact fallback.

Compare each combination with deployed and the frozen combined .85/.55 variants, reporting paired discordances and exact conditional binomial tests; use 10,000 seed-20261031 cluster bootstraps (source file for constructed trials, commit pair for histories, repository+commit pair for external cases) for headline accuracy, missed, wrong-silent, lost and false re-check contrasts. Nominal exploratory inference, no multiplicity-adjusted superiority claim. Define descriptive safety dominance in advance as no higher missed or wrong-silent rate, at least one strictly lower, and lost-rate increase <= 1 percentage point; separately mark inferential support only if both safety difference upper confidence limits are <=0. Always expose false re-check cost, placement and errors; descriptive dominance is not a certificate of semantic identity or workload benefit.
